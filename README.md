# Mukesh J & Priyanka B Wedding Website

This is a simple static wedding invitation website.

## Free hosting option: GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a new public repository, for example `mukesh-priyanka-wedding`.
3. Upload all files from this folder.
4. Open the repository **Settings → Pages**.
5. Under Source, choose **Deploy from a branch** and select `main` and `/ (root)`.
6. Save and wait for the site to publish.

Your website will have a free GitHub Pages address based on your GitHub username and repository name.

Files:
- `index.html` – website
- `invitation.png` – invitation image
- `wedding.ics` – wedding calendar file
- `reception.ics` – reception calendar file
